## Context

项目骨架已完整落地（gate + 3 node + 2 mesh 共 6 个服务，含完整存储层）。当前存在的工程问题：

4. **死代码**：[share/utils/util_time.go](file:///c:/Users/Administrator/IdeaProjects/server-cluster/share/utils/util_time.go) 三个函数全项目无调用

6. **配置每请求解析**：[mesh/account/logic/account.go](file:///c:/Users/Administrator/IdeaProjects/server-cluster/mesh/account/logic/account.go) 的 `loadServers` 每次请求都 `etc.Get().Scan()`

**不动的部分**：各服务 main.go 的显式编排流程（项目硬约束，due-chat 风格）、存储层 internal/store、errs/consts 错误码体系（`WithMessage` 被 player.go 使用，保留）。

## 改动清单

### 1. 新增 `internal/webx`：HTTP 公共层

新建两个文件：

- `internal/webx/response.go`：
  - `Response{Code int; Message string; Data interface{}}`（JSON tag 同现有 account 实现，保证前端契约不变）
  - `Success(c *fiber.Ctx, data interface{}) error`：code=0/message=success
  - `Fail(c *fiber.Ctx, err error)`：断言 `interface{ Code() int; Message() string }`（due codes.Err 满足），兜底 `consts.CodeInternalError`
- `internal/webx/server.go`：
  - `Start(name string, setup func(app *fiber.App))`：fiber.New(DisableStartupMessage) → setup 挂路由 → 从 `etc.Get("etc.http.addr")` 读监听地址（缺省 panic 提示补配置）→ log + Listen

配套配置：

- `mesh/account/etc/etc.yaml` 增加 `http: { addr: ":8080" }`
- `mesh/admin/etc/etc.yaml` 增加 `http: { addr: ":8081" }`
